欢迎来到我的博客！这篇文章由 Hugo + Stack 主题生成，部署在 GitHub Pages 上。

## 这套博客是怎么运作的

- 用 **Markdown** 写文章，存放在 `content/post/` 目录
- `git push` 到 GitHub 后，**GitHub Actions** 自动构建并发布
- 全程免费，无需服务器

## Markdown 排版示例

### 文字样式

支持 **加粗**、*斜体*、~~删除线~~、`行内代码`，以及 [链接](https://gohugo.io/)。
